# Архитектура

## Обзор

```
 iced UI (main.rs, view*.rs)
   │  Msg / Task
   ├── Engine (engine/mod.rs) ── Backend ──┬── RqbitBackend (librqbit)
   │     очередь, приоритеты               └── DemoBackend  (PITORRENT_DEMO)
   ├── Manager (plugins/) ── QuickJS ── HTTP/HTML/state
   ├── Settings, Categories (JSON в app_dir)
   └── Платформа: трей, автозапуск, ассоциации, уведомления, single-instance
```

Приложение построено по схеме Elm (iced): состояние в `App`, события — `Msg`, обработка в `App::update`, отрисовка в `view`.

## Точка входа (`main.rs`)

1. Разбирает аргументы: флаг автозапуска (`autostart::MINIMIZED_ARG`) и magnet/`.torrent` (`assoc::open_arg`).
2. `single_instance::acquire` — если приложение уже запущено, передаёт ему аргумент и завершается.
3. Запускает окно iced без системных рамок (1280×820, минимум 960×600), с вшитыми шрифтами Geist. При запуске из автозапуска и включённом «закрывать в трей» окно стартует скрытым.

Фильтры списка (`Filter`): все, загружаются, раздаются, завершены, на паузе, с ошибками. Разделы (`View`) — торренты, поиск и т. д.

## Движок (`engine/`)

- `Backend` — трейт над конкретной библиотекой: пауза/возобновление/удаление, выбор файлов, предпросмотр `.torrent` и magnet (без добавления), добавление, перенос данных, создание `.torrent`, снимок состояния (`snapshot`) и лимиты скорости.
- `Engine` — обёртка над бэкендом, добавляющая очередь: при превышении `max_downloads` / `max_seeds` торренты с наименьшим приоритетом ставятся на паузу (`State::Queued`) и автоматически возобновляются. Торренты, запущенные пользователем вручную (`forced`), очередью не останавливаются. Порядок и состояние очереди хранятся в `queue.json`. Лимиты `0` означают «без ограничений».
- Для magnet-ссылок метаданные можно получить заранее (`preview_magnet`), а перенос в папку категории откладывается до их появления (`pending_moves`).
- `Snapshot` — всё, что нужно интерфейсу за один опрос: список торрентов, общая скорость, число узлов DHT, порт и, для выбранного торрента, `Detail` (файлы, пиры, карта частей из `PIECE_CELLS` ячеек).
- `rqbit.rs` — реализация на librqbit; `demo.rs` — фиктивные данные.

## Плагины (`plugins/`)

Подробности для авторов — в [plugins.md](plugins.md). Внутри:

- `host.rs` — запуск QuickJS (лимиты: память 64 МБ, стек 1 МБ, таймаут), `prelude.js` строит объект `ctx` и скрывает нативные функции.
- `http.rs` — HTTP только к разрешённым хостам, cookie-jar на плагин, проверка редиректов теми же правилами, ограничение времени (15 с по умолчанию, максимум 30) и размера ответа (8 МБ).
- `manager.rs` — загрузка встроенных (`BUNDLED`) и установленных плагинов, поиск, `resolve`, `check`; максимум 200 результатов, таймаут поиска 45 с, отмена через `AtomicBool`.
- `store.rs` — настройки плагинов: обычные значения в `plugins.json`, пароли и cookie в keyring (`piTorrent / plugin:<id>:<key>`).

## Поиск (`search.rs`)

Запрос выполняется параллельно во всех включённых плагинах; у каждого источника свой статус (`Running` / `Done(n)` / `Failed`). Результаты кэшируются на 5 минут по ключу (запрос, плагин, категория), запросы не чаще раза в 1,5 с. Сортировка по названию, размеру, сидам, личерам, источнику, дате.

## Данные и настройки

- `settings.rs` — `Settings` (`settings.json`): тема, язык, трей, автозапуск, уведомления, папка загрузки, порт, DHT, лимиты очереди и скорости, включённые плагины. Папка данных `app_dir()` зависит от `PITORRENT_PROFILE`; старая папка `Tidepool` мигрирует автоматически.
- `categories.rs` — категории с путями, привязка по info hash (`categories.json`).

## Платформенный слой

- `single_instance.rs` — TCP-сервер на `127.0.0.1:47613` (для профиля — порт из хэша имени); команды `show`, `ping`, `open:<arg>`, сообщения до 16 КБ.
- `assoc.rs` — регистрация `.torrent` и `magnet:` в реестре Windows (`winreg`).
- `autostart.rs` — автозапуск (`auto-launch`) с аргументом «свернуто».
- `tray.rs`, `notify.rs`, `app_icon.rs`, `platform.rs` — трей, уведомления, иконка, мелкие платформенные функции.

## Интерфейс

- `view.rs`, `view_plugins.rs` — экраны (список, детали, добавление, настройки, плагины).
- `widgets.rs` — общие виджеты, дерево файлов (`TreeRow`, `build_tree`), шрифты.
- `theme.rs` — палитры (`Mode`: светлая/тёмная) и стили. `icons.rs` — SVG-иконки из `assets/icons`.
- `i18n.rs` — `tr`, `trf`; строки в `assets/locales/*.json`; язык `Auto` берётся из системы (`sys-locale`).
- `fmt.rs` — форматирование размеров, скоростей, времени.
