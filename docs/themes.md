# Темы

Тема — это JSON-файл, который накладывается на тёмную или светлую палитру: цвета, скругления, прозрачность, материал окна и шрифты. Код в темах не выполняется.

Выбрать тему можно в Настройки → Внешний вид → «Стиль темы». Встроенные темы: **piTorrent** (обычный вид) и **Fluent** (по токенам Fluent 2). Режим «Тёмная / Светлая» работает с любой темой, если в ней описаны оба режима.

## Где лежат темы

`<config dir>/piTorrent/themes/` (на Windows — `%APPDATA%\piTorrent\themes`). Подходит любой из вариантов:

- `имя.json`;
- `имя/theme.json` (папка, в которую можно положить и другие файлы темы).

Список читается при запуске. Тему из `.zip` можно добавить без перезапуска кнопкой «Выбрать .zip» в том же разделе.

## Импорт из zip

В архиве `theme.json` лежит в корне или в одной папке верхнего уровня. Тема распаковывается в `themes/<имя темы>/`, прежний каталог с таким именем заменяется, а сама тема сразу выбирается. Для безопасности:

- пути вне папки темы (`..`, абсолютные) отбрасываются;
- распаковываются только файлы `json`, `png`, `jpg`, `jpeg`, `webp`, `ttf`, `otf`, `txt`, `md`;
- не больше 200 файлов, 32 МБ на файл и 64 МБ всего;
- имя `piTorrent` зарезервировано.

## Формат

```json
{
  "name": "Моя тема",
  "base": "dark",
  "radius": 0.5,
  "opacity": 1.0,
  "backdrop": "mica",
  "font": "Segoe UI",
  "mono_font": "Cascadia Mono",
  "colors": { "acc": "#60CDFF" },
  "dark":   { "bg": "#202020C8", "isl": "#2B2B2B" },
  "light":  { "bg": "#F3F3F3C8", "isl": "#FFFFFF" }
}
```

Все поля необязательны, кроме `name` (без него берётся имя файла или папки).

| Поле | Значение |
|---|---|
| `name` | название в списке |
| `base` | `dark` или `light`: включить этот режим при выборе темы. Если не задано, режим остаётся прежним |
| `radius` | множитель всех скруглений (1.0 — как обычно, 0.5 — вдвое меньше). Точки, переключатели и полоски прогресса не масштабируются |
| `opacity` | прозрачность окна 0.3–1.0, ставится при выборе темы; потом её можно менять ползунком |
| `backdrop` | `none`, `mica` или `acrylic`: материал за окном (только Windows 11) |
| `font`, `mono_font` | семейства обычного и моноширинного шрифтов. Должны быть установлены в системе; применяются после перезапуска |
| `colors` | цвета для обоих режимов |
| `dark`, `light` | цвета для одного режима, перекрывают `colors` |

Цвет — `#RRGGBB` или `#RRGGBBAA` (последняя пара — прозрачность). Не указанные цвета берутся из встроенной палитры выбранного режима.

### Имена цветов

| Ключ | Где используется |
|---|---|
| `bg` | фон окна |
| `isl` | панели («острова») и диалоги |
| `ibd` | обводка панелей |
| `elev` | карточки внутри панелей |
| `input` | поля ввода |
| `line`, `bd` | разделители, рамки кнопок и диалогов |
| `hov`, `act`, `sel` | наведение, нажатие, выбранная строка |
| `txt`, `txt2`, `mute`, `faint` | текст: основной, вторичный, приглушённый, подсказки |
| `acc`, `acc_hov`, `acc_ink` | акцент (кнопки, переключатели), его наведение, текст на нём |
| `dl` | загрузка, фокус полей, ссылки |
| `seed`, `pause`, `err` | раздача, пауза, ошибка |
| `track`, `off` | дорожка прогресса, выключенный переключатель |

Встроенные темы лежат в `assets/themes/` и служат примерами: `pitorrent.json` содержит полную палитру, `fluent.json` — пример с прозрачностью, шрифтами и материалом.

## Как это устроено

- `src/themes.rs` — разбор `theme.json` (`Skin`), поиск тем на диске, импорт zip, встроенная тема `stock()`.
- `Palette::of(mode)` (`theme.rs`) собирает палитру из `assets/themes/pitorrent.json`; тест проверяет, что там есть все цвета в обоих режимах.
- `App::palette()` накладывает цвета выбранной темы, затем применяет прозрачность из настроек (`Palette::translucent`).
- Скругления: `theme::set_radius_scale` задаёт общий множитель, его применяет `border()` в `theme.rs`.
- Шрифты: `widgets::set_sans` / `set_mono` вызываются один раз при старте, до создания окна.
- Материал окна: `platform::set_backdrop` (`DWMWA_SYSTEMBACKDROP_TYPE`); окно всегда создаётся прозрачным, а цвета с альфой дают нужную прозрачность.
- В `settings.json` хранятся `skin` (имя темы), `theme`, `opacity` и `backdrop`.
